LLMTray は、お使いのハードウェア上で AI モデルを動かします。チャットも、絵を描くのも、曲作りも、アプリ向けの OpenAI 互換 API も、すべて Apple silicon 上で。アカウントもクラウドも必要ありません。

データセンターに頼らず、自分のハードウェアで。
お使いのハードウェアは、すでに十分な力を持つ AI マシンです。LLMTray がその力を引き出します。モデルは手元で動くので、プロンプトもファイルも結果も外に出ることはなく、サーバの順番待ちもありません。

オープンモデルとチャット
• お使いのハードウェアに合うモデルを選べます。ガイド付きのセットアップが、メモリに合ったサイズを提案します。
• 「設定」で Hugging Face から MLX モデルを追加でダウンロードできます。
• 視覚に対応したモデルは画像を読み取り、推論するモデルは思考プロセスを表示します。
• タブ、履歴、検索、一時チャット、長いチャットの自動圧縮。

あなたのファイルを、出典付きで
• プロジェクトは、チャットを専用の指示やドキュメントとともにまとめます。
• PDF、Word、Markdown、テキストファイルをプロジェクトにドロップすると、モデルがその中を検索し、使用したページを出典として示します。
• 短い参考資料をピン留めすると、プロジェクト内のすべての回答がそれを参照します。

画像も曲も、お使いのハードウェアで
• チャットで絵を頼むと、お使いのハードウェア上でそのまま描かれます。
• 画像を添付して、変えたいところを伝えるだけで編集できます。
• 短い説明から、ボーカルと歌詞のある曲やインストゥルメンタルを作れます。
• 作成者モードでは、作成が始まる前にプロンプト、サイズ、モデルを調整できます。

いつでもあなたが管理できるツール
• 日付と時刻、計算機のツールを内蔵。ウェブ検索、ニュース、Wikipedia、天気などは、オンにした場合にのみ使われます。
• 許可したフォルダの整理をチャットに任せられます。新しいフォルダ、移動、名前の変更が提案され、あなたが承認するまで何も変更されません。「元に戻す」で取り消せます。

コーディングエージェントやアプリを接続
• LLMTray は、お使いのハードウェア上（localhost）で OpenAI 互換 API を提供します。コーディング API に対応したアプリやコーディングエージェントの接続先に指定してください。
• 各モデルには短いエイリアスが付き、アプリは名前でモデルを切り替えられます。
• ほかのデバイスからのネットワークアクセスは、オンにしない限りオフです。

速さのために
• サンプリング、KV cache の量子化、投機的デコードを、モデルごとのプロファイルで設定できます。
• 内蔵のベンチマークがお使いのハードウェアを計測し、それに合わせてサーバを調整できます。

頼んでいないことは、何もしません
• 負荷の大きい機能はすべて、オンにするまでオフのままです。選ぶまで何もダウンロードされません。
• アカウントなし、広告なし、トラッキングなし。匿名の使用統計は任意で、「設定」でオフにできます。
