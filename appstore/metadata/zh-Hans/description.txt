LLMTray 在你自己的硬件上运行 AI 模型。聊天、画图、写歌，还能为你的应用提供兼容 OpenAI 的 API，一切都在 Apple silicon 上完成，无需账户，无需云端。

少依赖数据中心，多用自己的硬件。
你的硬件本身就是一台强大的 AI 机器。LLMTray 让它发挥作用：模型就在本地运行，你的提示词、文件和结果绝不会离开它，也不用在服务器队列里等待。

与开放模型聊天
• 挑选适合你硬件的模型：引导式设置会根据内存推荐合适的大小。
• 在“设置”中从 Hugging Face 下载更多 MLX 模型。
• 支持视觉的模型能读懂你的图像；会推理的模型会展示思考过程。
• 标签页、历史记录、搜索、临时对话，以及长聊天的自动压缩。

你的文件，附带来源
• 项目把聊天与各自的指令和文档归在一起。
• 把 PDF、Word、Markdown 和文本文件拖入项目：模型会搜索其中内容，并标明引用的页码。
• 固定一份简短的参考资料，项目中的每个回答都能看到它。

图像与歌曲，在你的硬件上生成
• 在聊天中要一张图：它就在你的硬件上直接画出来。
• 附上一张图像并说明要改什么，即可编辑。
• 凭一段简短描述，生成带人声和歌词的歌曲，或一段纯音乐。
• 创作者模式让你在生成之前调整提示词、尺寸和模型。

工具始终由你掌控
• 内置日期与时间、计算器等工具；网络搜索、新闻、Wikipedia、天气等，只有在你开启后才会启用。
• 让聊天整理你允许的文件夹：它会提议新建文件夹、移动和重命名，在你批准之前不会有任何改动。撤销即可恢复原状。

连接你的代码代理和应用
• LLMTray 在你的硬件上（localhost）提供兼容 OpenAI 的 API。让任何支持编程 API 的应用或代码代理指向它即可。
• 每个模型都有一个简短的别名，应用可以按名称切换模型。
• 面向其他设备的网络访问默认关闭，除非你手动开启。

为速度而生
• 按模型设置配置方案：采样、KV cache 量化和推测解码。
• 内置基准测试会测量你的硬件，并可据此调优服务器。

不做你没要求的事
• 所有重型功能在你开启之前都保持关闭，在你选择之前不会下载任何内容。
• 无账户、无广告、无跟踪。匿名使用统计为可选项，可在“设置”中关闭。
